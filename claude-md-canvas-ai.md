### AI-designed free slides (canvas)

`POST /api/ai-generator/canvas-slides` (`app/ai-generator/canvas-slides/`) uses the configured AI provider (Groq, Gemini or Ollama, same primary/fallback plan as the bank generator) to create free slides from a description or from an uploaded document (Markdown from `POST /api/ai-generator/upload`). The admin entry point is «Añadir diapositiva libre» → «Generar con IA» (`public/js/admin/modules/slides-canvas-ai.js`). The result has the same shape as `/api/canvas-slides/import` and goes through `_lienzoAddToGame` (`slides-canvas-import.js`), with its own texts: one slide opens in the editor, several are appended after confirming.

- **The AI never places elements.** `prompt.js` asks for `{ "theme", "slides": [{ "layout", …fields }] }`, where each slide uses one of 13 layouts: cover, statement, bullets, text, cards, steps, process, flow, comparison, stat, quote, timeline and question. The JSON can also carry tones (positive, negative, neutral, accent, accent2) and icon names from `icons.js`. This keeps the output usable with small local models; it was tried with 7B–27B Ollama models.
- **Parsing and sanitising.** `spec.js` sanitises the JSON: layout aliases, Markdown and bullet markers stripped, word-boundary length caps, list sizes, and a "text" that is really a list becomes bullets. `generator.js` tolerates code fences, trailing commas and truncated JSON (it closes open strings and brackets). It tries each provider twice and then falls back to the next one.
- **Layout and text fitting.** `layouts-*.js` lay slides out on the 1920×1080 canvas with the palettes in `themes.js` (claro, noche, ciruela, oceano, jungla, papel). `text-fit.js` sizes text boxes without a browser: it uses measured DM Sans glyph widths and per-font averages for the other fonts, balances 2–3-line texts so no word is left alone on the last line, and never sizes a box so that a word gets split. Boxes are measured after balancing.
- **Import path.** `build.js` packs the canvases as a `.xiroslide`; icons and the stat donut become SVG assets. `generator.js` runs the package through `importSlidePackage`, so AI slides get exactly the validation of a file import (svg-guard, normalizeCanvas, canvasSchema) and their SVGs land in `/uploads/` with hashed names.
- **Errors.** Codes: `AI_NOT_CONFIGURED` (503), `AI_CANVAS_PROMPT_REQUIRED` and `AI_CANVAS_PROMPT_TOO_LONG` (400), `AI_CANVAS_GENERATION_FAILED` (502). Warning `AI_FEWER_SLIDES` is shown via `WARNING_KEYS` in `slides-canvas-package.js`. Like `/generate`, the route writes a space every 15 s so proxies do not cut the wait, so a late error arrives as 200 with `{ error, code }`. A client disconnect is detected with `res.on('close')`, because in modern Node `req` 'close' fires once the body has been read.
- **Adding a layout.** Four steps:
  1. Add a sanitiser in `spec.js`, and add the layout to `WITH_HEADER` if it has a title and a note.
  2. Register the builder in `build.js`.
  3. Add a line to `CATALOG` in `prompt.js`.
  4. Add a sample to `__tests__/helpers/canvas-slides-fixtures.js`. `canvas-slides-layouts.test.js` imports every sample in every theme and checks bounds, element count, text fit and theme contrast.
